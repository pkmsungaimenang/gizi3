Logika NIK & Tanggal Lahir

1. Jika file memiliki NIK, data NIK dipertahankan.

2. Jika file tidak punya NIK, sistem membuat NIK baru (Kode 16.02.15).

3. Jika file memiliki Tanggal Lahir, dipakai sebagai acuan usia.

4. Jika Tanggal Lahir kosong tapi ada NIK, tanggal lahir ditebak dari digit NIK (DDMMYY).
